# ZombieShooter — Halfway Project Review

**Project:** Group 3D Game Project  
**Game:** ZombieShooter  
**Development Platform:** Unity 6.5  
**Repository:** https://github.com/dcabana777/zombie-shooter

## 1. Current Game Description

ZombieShooter is a 3D zombie survival shooter currently being developed in Unity. The intended gameplay involves controlling a player character, using weapons to defend against zombies, and surviving encounters in a playable arena.

The team is developing the game through separate systems, including player controls and weapons, zombie AI, zombie models and animations, map design, and user interface integration.
